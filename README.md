# Sunshine Task

Sunshine Task es una aplicación móvil desarrollada como proyecto académico por un equipo de tres estudiantes.

La aplicación tiene como objetivo ayudar a los usuarios a organizar sus tareas, establecer fechas límite, controlar su estado y adjuntar evidencias que permitan demostrar que una tarea fue realizada.

El proyecto se desarrolla de manera progresiva mediante diferentes cambios y commits, permitiendo observar la evolución de la aplicación durante su elaboración.

## Objetivo

Crear una aplicación sencilla que permita a los usuarios organizar sus tareas y llevar un mejor control de sus actividades.

### Funcionalidades principales

La aplicación permite:

- Crear tareas.
- Agregar una descripción.
- Asignar una categoría.
- Establecer una prioridad.
- Establecer una fecha límite.
- Cambiar el estado de una tarea.
- Buscar tareas.
- Filtrar tareas.
- Consultar un resumen de las tareas.
- Adjuntar archivos como evidencia.
- Abrir y eliminar evidencias.
- Eliminar tareas.

## Funcionamiento de la aplicación

Al ingresar a Sunshine Task, el usuario puede visualizar sus tareas y consultar un pequeño resumen de su actividad.

Cada tarea puede tener uno de los siguientes estados:

- Pendiente.
- En progreso.
- Completada.

También es posible establecer diferentes niveles de prioridad:

- Baja.
- Media.
- Alta.
- Urgente.

Cuando una tarea tiene una fecha límite, la aplicación permite identificar si esta se encuentra vencida.

## Evidencias

Una de las principales funcionalidades de Sunshine Task es la posibilidad de agregar evidencias a las tareas.

Por ejemplo, si un estudiante debe realizar una investigación, puede adjuntar un PDF, una imagen u otro documento relacionado con la actividad.

De esta manera, la aplicación permite mantener la tarea y su respectiva evidencia en un mismo lugar.

## Guardado de información

La aplicación almacena las tareas en el dispositivo, permitiendo conservar la información cuando el usuario cierra y vuelve a abrir la aplicación.
